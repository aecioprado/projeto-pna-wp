# Ícones do tema PNA

| Arquivo | Uso | Origem |
|---|---|---|
| `sino.svg` | Notificações no cabeçalho | Provisório: [Tabler Icons](https://tabler.io/icons) 3.48 (MIT, ver `LICENSE-tabler.txt`) |
| `usuario.svg` | Perfil no cabeçalho | Provisório: Tabler Icons 3.48 (MIT) |
| `seta-direita.svg` | Separador do breadcrumb | Provisório: Tabler Icons 3.48 (MIT) |

Os ícones provisórios têm forma parecida com os do Figma e serão substituídos pelos SVGs exportados do Figma assim que possível. Para trocar, basta sobrescrever o arquivo mantendo o mesmo nome.

Regras para qualquer ícone novo:

- `viewBox` definido e sem `width`/`height` fixos (o tamanho vem do CSS).
- Cor sempre `currentColor` (a cor vem do texto ao redor, ou seja, dos tokens).
- Registrar aqui a origem e a licença. Ícones do SVG Repo têm licenças variadas: confira uma a uma.
